## Sobre

O **OutTime** é uma página de previsão do tempo simples e direta: abre já mostrando o clima de onde
você está e permite buscar qualquer cidade.

## Visão Geral

O projeto permite:

- usar a **localização do navegador** para mostrar o clima atual
- buscar o clima de **qualquer cidade**
- ver temperatura, sensação térmica, umidade e velocidade do vento
- acompanhar a previsão dos **próximos dias**
- tudo em português, com dados da [WeatherAPI](https://www.weatherapi.com/)

## Rodando Localmente

Projeto estático, sem dependências: basta abrir o `index.html` no navegador.

> A chave da WeatherAPI fica no próprio `index.html`. Para usar a sua, crie uma conta gratuita na
> WeatherAPI e troque o valor de `apiKey`.
